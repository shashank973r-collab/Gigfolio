# GigFolio — Verified Gig Worker Platform

A trust layer for the unorganized gig economy in India.

## Tech Stack
- React (Vite) + Tailwind CSS
- Node.js + Express
- MongoDB
- Blockchain (ethers.js)
- Gemini AI

## Features
- Worker verified portfolios
- QR-based client review system
- DigiLocker mock ID verification
- Blockchain hash verification
- AI-powered worker recommendations
- Real-time appointment notifications

## Setup
cd client && npm install && npm run dev
cd server && npm install && node server.js
